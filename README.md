`login-app` é uma aplicação de exemplo para implementar um sistema básico de login/autenticação. O objetivo é demonstrar como estruturar um fluxo de login (e potencialmente registo) de utilizadores de forma simples — ideal para aprender os conceitos ou servir como base para projetos mais complexos.
